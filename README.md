# MEGA HIT MUSIC — официален сайт

Статичен сайт на музикалния лейбъл MEGA HIT MUSIC с вграден админ панел.
Цялото съдържание се пази във Firebase Realtime Database.

## Структура

```
index.html            Публичен сайт (една страница, динамични секции)
admin.html            Админ панел (noindex)
css/style.css         Стилове на публичния сайт
css/admin.css         Стилове на админ панела
js/firebase-config.js Инициализация на Firebase (ES module)
js/data.js            Начални данни (използват се при празна база)
js/store.js           Четене/запис на съдържанието
js/auth.js            Вход, сесии, управление на потребители (PBKDF2)
js/admin.js           Логика на админ панела
database.rules.json   Правила за Realtime Database
FIREBASE-SECURITY.md  Как работи защитата и как да се затегне
```

## Админ панел

Адрес: `admin.html` (линк има и в долния колонтитул на сайта).

Първи администратор (създава се автоматично при първо влизане, ако базата е празна):

| Потребителско име | Парола |
|---|---|
| `alex4o` | `Aleks2010$` |

**Смени паролата веднага** от „Моят профил“.

Възможности:

- **Изпълнители, Сингли, Събития, Новини** — добавяне, редактиране, изтриване.
- **Съобщения** — всичко изпратено през контактната форма, с отговор по имейл.
- **Потребители** — нови профили с роля *администратор* или *редактор*.
- **Моят профил** — смяна на собствената парола.

Редакторите управляват съдържанието, но не виждат секция „Потребители“.

## Локално пускане

```bash
python3 -m http.server 8080
```

Отвори `http://localhost:8080`.

> Сайтът трябва да се отваря през `http://localhost` или `https://`, не през `file://`,
> защото криптографията за паролите (Web Crypto) работи само в защитен контекст.

## Публикуване

GitHub Pages: Settings → Pages → Branch `main`, папка `/ (root)`.
Сайтът ще бъде достъпен на `https://gabcho0110.github.io/megahitmusic/`.

Firebase не изисква настройка на домейна за Realtime Database.
